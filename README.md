# 사계절 배경화면

폭포와 고양이가 있는 아이패드용 움직이는 배경화면이에요.

- 좌우로 밀기: 계절 바꾸기
- 위아래로 밀기: 시계 켜기/끄기
- 빈 곳 두 번 톡: 자동(달력 기준 계절)
- 고양이 톡: 산책 / 나무 톡: 잎이 흔들리고 떨어짐

## GitHub Pages로 열기
1. 이 폴더의 파일을 모두 저장소 맨 위(루트)에 올려요.
2. 저장소 Settings > Pages > Branch를 `main` / `(root)`로 정하고 Save.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열려요.
4. 아이패드 Safari에서 열고 공유 > 홈 화면에 추가.
